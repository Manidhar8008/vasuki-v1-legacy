# Vasuki

Vasuki is a local-first personal AI/data orchestration project built in Termux.

## Current capabilities

- File indexing and metadata extraction
- SQLite-based memory and entity storage
- OCR and document-processing pipeline
- Health-check and verification scripts
- Local data-processing logic
- Modular tools and scripts for orchestration

## Project structure

```text
vasuki/
├── scripts/        # Core automation and health-check scripts
├── tools/          # Utility tools and integrations
├── data/           # Local runtime data (not committed)
